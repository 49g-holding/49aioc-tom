# DR-0002 · TOM v0.3.0: closing the blueprint

- **Date:** 2026-10-15
- **Decided by:** the directions given to `[ORG]AIOC-OCO` for this draft (the decider is recorded in the private holders register), and `[ORG]AIOC-OCO`'s rulings on the points four independent reviews left contested. This is a decision on this repository only, not a decision of 49GAION.
- **Recorded by:** `[ORG]AIOC-OCO`
- **Status:** in force for this repository's draft

## Decision

1. **The release is fully about the operating model.** It holds no review record, engine identity, count of checkers, review-level decision value, engine-related listed type, or AI, agent, engine, automation or tool word. A release lint, run by code, enforces this at T9.
2. **One Input Pack, one adapter for each source type.** The Input socket hands the engine one versioned, content-addressed Input Pack. Atomising and labelling happen there, once. Each source type plugs in through its own adapter file; the first is Source Lifecycle's. An adapter only reads. Asking and filing stay with Source Lifecycle.
3. **Answers and decisions arrive as new pack versions.** A re-base is a run-control decision of the TOM Design Lead. SL-A8 is amended to read answers at their own snapshots.
4. **The earlier work is a case study.** Its rules are reused; its tests count for nothing; its code is not wired in. The order category, the evaluator's questions, the expertise lens, the understanding check and the findings offered as new are restored. Gate B is mapped, and its two delegable parts restored.
5. **Nine stages.** Each is one run state, with one input, one output and one done-test. Review is a rule across all stages; asking is a service.
6. **The Review Panel rule.** 3 to 5 engines, at least 2 families, none of an author's family in normal mode; a blind pass; at most two debate rounds held to quotes; settlement by code, without a vote; the TOM Design Lead rules on contested `MATERIAL` findings only. Reduced mode needs the TM Cell's permission (default no) and the Design Lead's acceptance at the run preview; the Requesting Authority is told, not asked.
7. **Group Assembly becomes Hand-offs.** There is no model of the whole; the group-platform alignment line goes.
8. **The blueprint is closed.** A closure statement; `lifecycle_state: designed`; one list of human decisions; field lists for every new object; carry-forward designed.
9. **Renamed while nothing has run.** Design Order becomes Design Brief; Formation Report becomes Readiness Report; Order Reconstruction becomes Request Reconstruction; and the codes of the rename table follow.
